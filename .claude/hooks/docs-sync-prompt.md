2. Прочитай изменённый код (src/main, pom.xml, docker-compose.yml, Dockerfile, .gitlab-ci.yml).
3. Обнови только то, что разошлось с кодом:

   - docs/architecture.md: конвейер обработки, модули, алгоритмы, статус этапов;

   Запланированное, но не реализованное, помечай как план.

   (коммить только документацию, чужие изменения в индексе не трогай), затем `git push origin HEAD`.
